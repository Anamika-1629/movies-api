# Movies API 🎬

A basic REST API project built using Spring Boot and MongoDB for managing movie data and reviews.

## Features
- Store movie details
- Store movie reviews
- REST API architecture
- MongoDB database integration
- Layered structure:
    - Controller
    - Service
    - Repository
    - Model

## Project Structure
```text
src/
 ├── main/
 │    ├── java/
 │    │     ├── controller/
 │    │     ├── service/
 │    │     ├── repository/
 │    │     └── model/
 │    └── resources/
 │          └── application.properties
```
